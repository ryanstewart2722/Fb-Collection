Editor

Paste a GitHub access token to edit the site. It's saved only in this browser.

How to make a token
  1. Open github.com/settings/personal-access-tokens/new
  2. Name: Fb-Collection editor. Expiration: up to you (e.g. 1 year).
  3. Repository access → Only select repositories → Fb-Collection.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate token, copy it, paste it above.
